# Online Shop

A Java 21 application representing an online electronics store.

## Project status

The project is currently under development.

## Technologies

- Java 21
- Maven
- JUnit 5
- AssertJ
- Git
- GitHub Flow

## Features

The planned application will support:

- product management,
- configurable computers and smartphones,
- shopping cart management,
- order processing,
- invoice generation,
- data persistence,
- concurrent and asynchronous order processing.

## Branching strategy

The project uses the following branch structure:

- `master` – stable production-ready code,
- `test` – integration and testing branch,
- `dev` – active development branch,
- `feature/TASK-*` – new features,
- `fix/TASK-*` – fixes,
- `bug/TASK-*` – bug fixes.
